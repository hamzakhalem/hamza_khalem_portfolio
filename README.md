## Getting Started

Clone the repository:

```bash
git clone https://github.com/hamzakhalem/hamza-khalem-portfolio.git
cd hamza-khalem-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
